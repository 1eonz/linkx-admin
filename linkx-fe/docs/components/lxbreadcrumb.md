# LxBreadcrumb 面包屑

展示当前页面在信息架构中的位置。组件渲染原生链接，但不依赖 Vue Router；SPA 路由由宿主通过 `select` 事件接管。

## 交互示例

<script setup lang="ts">
import Basic from '../../src/components/LxBreadcrumb/demo/basic.vue';
</script>

<Basic />

示例仅接管普通主键点击及 Enter 激活，调用 `preventDefault()` 后由宿主更新 `items`，最后一项随之成为当前页。Ctrl/⌘、Shift、Alt 和中键保留浏览器语义；演示链接是本页占位锚点，不访问业务后端。Demo 通过 `vp-raw` 避免文档站抢先接管链接，业务宿主无需使用该文档专属类。

可切换浅色/HUD、长路径、空路径并恢复默认路径。组件同步展示可信条目，不自行请求数据，因此加载、权限不足及路由失败的反馈由宿主提供，不能将空 `items` 当作请求成功。

回退后原链接会变成当前页文本，示例宿主将焦点移到结果说明；实际应用应在路由完成后将焦点移到目标页面标题或主内容，公共组件不替宿主决定页面焦点。

## Props

| 名称        | 类型                 | 默认值 | 说明                         |
| ----------- | -------------------- | ------ | ---------------------------- |
| `items`     | `LxBreadcrumbItem[]` | `[]`   | 从根级到当前页的条目。       |
| `separator` | `string`             | `'/'`  | 相邻条目之间显示的分隔文本。 |

`LxBreadcrumbItem` 包含必填 `title: string` 和可选 `to: string`。只有非末尾且带 `to` 的条目渲染为链接；末尾条目始终以 `aria-current="page"` 表示当前页面。

## Events 与插槽

| 事件     | 参数                        | 说明                                             |
| -------- | --------------------------- | ------------------------------------------------ |
| `select` | `(item, event: MouseEvent)` | 点击可导航条目时发出；宿主可阻止默认跳转并导航。 |

默认插槽追加到导航内容末尾，可放置当前范围或环境标记。空 `items` 不渲染空列表，仍显示默认插槽。组件提供 `aria-label="面包屑导航"` 和有序路径列表；链接可用 Tab 聚焦并按 Enter 激活，键盘焦点显示贴合链接的轮廓。

## 使用边界

- 组件不调用 Router，也不自动阻止链接导航。SPA 宿主应先排除 `defaultPrevented`、非主键和修饰键，再阻止普通点击并导航；`href` 应由宿主 Router 生成，保持 history base、参数及原生新标签行为。
- 当前页标题应来自可信路由元数据；超长标题单项省略并保留 `title` 和完整可访问名称，页面标题也应提供完整名称。路径按层级换行，分隔符与后一级保持一组，插槽独立换行，避免撑宽页面。
- 链接最小高度 24px，粗指针设备扩展至 44px。当前页和无目标的层级均为不可点击文本；不额外加入无业务含义的动画。
