# LxActionButtons 行内操作

表格行内操作按钮组：外显按钮走 `LxButton` 文字形态内核
（拍板 #11：表格行内一律 text 形态），支持语义色四档与自定义色。
超出 `max` 数量的项目会折叠进可键盘操作的「更多」列表，
并随权限过滤或条件显隐动态增减。

## Props

| 名称        | 说明                                                                                               | 类型             | 默认值 |
| ----------- | -------------------------------------------------------------------------------------------------- | ---------------- | ------ |
| `actions`   | 操作列表                                                                                           | `LxActionItem[]` | `[]`   |
| `max`       | 最多直接显示的数量；小数向下取整，负数按 `0` 处理，超出项折叠进「更多」；表格场景建议不超过 `3` 项 | `number`         | `3`    |
| `more-text` | 折叠菜单触发文字                                                                                   | `string`         | `更多` |

### LxActionItem

| 字段        | 说明                                                               | 类型                                                           |
| ----------- | ------------------------------------------------------------------ | -------------------------------------------------------------- |
| `label`     | 显示文字                                                           | `string`                                                       |
| `type`      | 语义色档（见下方映射表）                                           | `'primary' \| 'success' \| 'warning' \| 'danger' \| 'default'` |
| `textColor` | 自定义文字色（语义色之外的场景）；hover 浅底按该色自动派生         | `string`                                                       |
| `icon`      | 可选辅助图标（文字左侧）；行内操作仍须保留文字标签                 | `LxIconName`                                                   |
| `hidden`    | 条件隐藏（业务侧权限过滤后传入）                                   | `boolean`                                                      |
| `disabled`  | 禁用该项并阻止点击事件                                             | `boolean`                                                      |
| `onClick`   | 点击回调（可选）：先派发统一 `click` 事件后调用，免父级按 key 分发 | `(action: LxActionItem) => void`                               |
| `key`       | 列表稳定键；省略时由名称和顺序生成                                 | `string`                                                       |
| `auth`      | 未传时按公开操作显示；显式空值、无权限源或权限不匹配时隐藏该项     | `string \| string[]`                                           |
| `meta`      | 业务透传                                                           | `Record<string, unknown>`                                      |

### 语义色档映射（2026-09-29 两项目 192 例全量调研拍板）

| 语义               | `type` 值 | 颜色 |
| ------------------ | --------- | ---- |
| 编辑/详情/常规操作 | `primary` | 蓝   |
| 删除/禁用/解绑     | `danger`  | 红   |
| 启用/恢复/拒绝     | `warning` | 橙   |
| 激活/正向授权      | `success` | 绿   |

`default` 兼容旧值，渲染与 `primary` 同为蓝色文字形态。

### Events

| 名称    | 说明                           | 回调                     |
| ------- | ------------------------------ | ------------------------ |
| `click` | 任一操作被点击（含折叠菜单内） | `(action: LxActionItem)` |

## 使用铁律

- 行内操作一律文字形态（组件内置），禁止实底按钮（拍板 #11）。
- 默认使用纯文字；需要强化识别时允许左置辅助图标，但必须保留文字标签（设计拍板 #2）。禁止纯图标行内操作。
- 语义色按映射表取档：编辑=primary、删除/禁用=danger、启用/恢复=warning、激活/授权=success；折叠进「更多」后颜色保持一致。
- 危险操作（删除/停用）标 `type: 'danger'`，点击后必须接 lxConfirm 二次确认。
- 可由业务侧通过 `hidden` 或不传入操作预过滤；配置 `auth` 时由组件按宿主权限源过滤。权限或显隐变化后「更多」入口自动增减，无需手动管理。
- 「更多」支持点击、Tab/Enter/Space 与 Escape；Escape 或选择溢出项后焦点回到触发按钮，焦点移出或点击外部时收起但保留用户的新焦点位置。
- 窄屏下操作按钮和菜单项至少 44px 高；超长操作名称允许换行，不撑宽页面。
- 提供 `auth` 时使用宿主通过 `setupLxPermission` 注入的权限过滤；未配置权限源、当前用户无对应权限或权限码为空时均隐藏该操作，权限变化会同步更新外显项与「更多」列表。
- 省略 `auth` 表示公开操作并保持显示；不要用空字符串或空数组表示公开操作，它们会按无权处理并隐藏。
- `warning` 菜单文字使用主题专用文字令牌，浅色和 HUD 主题均满足小字号对比度要求。
