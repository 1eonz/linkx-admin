# LxDutyCalendar 排班日历

用于展示一个月的排班摘要。组件只处理日历网格、月份导航和选择事件；数据查询、编辑弹窗及业务权限由宿主负责。

示例使用当前月份的本地内存数据，可切换周起始日、自定义单元格和 HUD 深色主题。空数据、加载、失败及只读状态由宿主包装层演示，不发起网络请求，也不代表组件提供对应状态属性。

## Props

| 名称        | 类型            | 默认值 | 说明                                                                                |
| ----------- | --------------- | ------ | ----------------------------------------------------------------------------------- |
| `month`     | `string`        | 当前月 | 显示月份，格式为 `YYYY-MM`；建议配合 `v-model:month` 使用。无效值或空值显示当前月。 |
| `shifts`    | `LxDutyShift[]` | `[]`   | 排班摘要列表，按 `date` 分组；每个日期最多显示前三项，其余显示数量提示。            |
| `weekStart` | `0 \| 1`        | `1`    | 每周起始日：`0` 为周日，`1` 为周一。                                                |

### `LxDutyShift`

| 字段     | 类型       | 必填 | 说明                                                         |
| -------- | ---------- | ---- | ------------------------------------------------------------ |
| `date`   | `string`   | 是   | 排班日期，格式为 `YYYY-MM-DD`。                              |
| `label`  | `string`   | 是   | 班次名称，例如早班、中班或夜班。                             |
| `status` | `LxStatus` | 否   | 语义状态，默认 `processing`；具体颜色由 lx-ui 主题令牌提供。 |
| `count`  | `number`   | 否   | 班次人数；未提供时不显示人数。                               |

## Events

| 名称           | 参数                 | 说明                                               |
| -------------- | -------------------- | -------------------------------------------------- |
| `update:month` | `month: string`      | 用户切换月份或键盘移动跨出当前 42 格时发出新月份。 |
| `cell-click`   | `date: string`       | 用户点击日期，或在日期格获得焦点时按 Enter/空格。  |
| `shift-click`  | `shift: LxDutyShift` | 用户点击默认渲染的班次按钮。                       |

## Slots

| 名称   | 参数                                      | 说明                                                             |
| ------ | ----------------------------------------- | ---------------------------------------------------------------- |
| `cell` | `{ date: string; shifts: LxDutyShift[] }` | 覆盖日期格内的默认班次摘要；日期数字和日期选择交互仍由组件提供。 |

## 键盘与状态

- 日历包含六周、42 个日期格。Tab 进入当前焦点日期；方向键按日或按周移动，Home/End 移到本周首尾，Enter/空格选择日期。
- 日期格采用 `grid`、`row`、`columnheader` 和 `gridcell` 语义；今天带有 `aria-current="date"`，月份标题会在切换后播报。
- 焦点移动越过可见网格边界时，组件切换到目标日期所在月份、发出 `update:month` 并保留日期焦点。
- 每格最多显示三个班次；班次通过原生按钮操作，按钮名称包含日期、班次和可选人数。使用 `cell` 插槽后，插槽内容由宿主负责交互。
- 空排班由 `shifts=[]` 表示。加载、请求错误和只读/禁用由宿主管理；组件不发请求，也没有 `loading`、`error` 或 `disabled` props。只读宿主可用 `inert` 阻止后代交互。
- 非本月日期使用表头背景区分，不降低整格透明度，确保日期文字和班次内容保持可读对比度。
- 窄屏日历在组件内部横向滚动，页面本身不扩宽；月份导航按钮在窄屏保持至少 44×44px。组件没有额外过渡动画。
