# 浏览器证据：Assessment A

此文件归档 Assessment A 的浏览器检查事实。仅使用 4177 临时预览和当前组件源码；没有读取 B 评审或 detector 产物。

- 首次尝试指定的 `http://127.0.0.1:4174/components/lxcheckbox` 时，IAB 返回 `ERR_CONNECTION_REFUSED`；本机端口查询显示 4174 无监听。
- 主 Agent 随后提供临时 4177 预览。独立 IAB 标签 2 成功访问 `http://127.0.0.1:4177/components/lxcheckbox` 与 `/components/lxradio`。
- 评审没有启动、停止或重启服务。4177 由主 Agent 负责结束。

## 观察记录

- Checkbox，1280×720，浅色：权限组有勾选、半选、未选和带原因的禁用项；两个禁用已选/半选回显位于单独面板。状态摘要跟随选择值。
- Checkbox，1280×720，HUD：背景切为深色，选中/半选采用 HUD 主色，禁用已选/半选使用中性框体。
- Checkbox，375×812，浅色与 HUD：选项区域无横向溢出；水平通知渠道在窄屏换行；禁用跨区移送文字完整显示。
- Radio，1280×720，浅色：白底蓝心靶环状态明确；垂直组选项和禁用原因均可辨认。改选“应急处突”后，状态区显示“响应等级 选中：emergency”。
- Radio，375×812，HUD：卡片与长标题自然折行，无横向溢出；选中靶环使用 HUD 蓝色。ArrowRight 可在组内把选中值从“日常勤务”切至“应急处突”，并显示键盘焦点环。

## 当前渲染值

在触屏仿真启用的 375×812 窄屏视口中，浏览器 `matchMedia('(hover: none)')` 与 `matchMedia('(pointer: coarse)')` 均返回 `true`。Checkbox 与 Radio 的选项高度均为 44px。

Checkbox 禁用 label 的 DOM 计算样式：

| 主题 | 文字色 | 禁用框背景 |
|---|---|---|
| 浅色 | `rgb(144, 147, 153)`（`#909399`） | `rgb(242, 244, 248)` |
| HUD | `rgb(148, 163, 184)`（`#94a3b8`） | `rgb(22, 35, 58)` |

Radio HUD 选中项文字为 `rgb(56, 189, 248)`（`#38bdf8`），未选项文字为 `rgb(148, 163, 184)`（`#94a3b8`）。
