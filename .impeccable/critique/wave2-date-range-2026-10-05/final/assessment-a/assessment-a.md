# LxDatePicker 修后 Assessment A：纯设计评审

Method: Assessment A only (design review in a fresh Playwright BrowserContext/Page; no Assessment B or detector evidence used)

目标：`http://127.0.0.1:5180/components/lxdatepicker`  
评审日期：2026-10-05  
模式：Operate（日期区间控件）；承载页面为 Read（组件文档）。

## 设计特异性

**判断：组件具有明确的 LxForm 设计身份，类别基础仍沿用熟悉的 Element Plus 日历。** 实际页面将 32px 触发器、4px 圆角、主色焦点、中文「至」、周一起始和连续选区带组合在一起；字段语境是专项布控与研判，快捷预设为「今日 / 本周 / 近30天」。这与标本 06 的表单规范相符。它不是换个颜色即可用于任意产品的默认控件，但桌面日历网格本身仍是标准企业日期选择模式，品牌表达主要落在令牌、文案和状态处理。

默认截图中实际 CSS 生效：桌面触发器为 32px 高、4px 圆角和令牌内描边；普通弹层为 648×331px、双月显示；HUD 主题开关在 demo 中可改变弹层主题。窄屏触发器和快捷项的 44px 触控目标规则也由源码定义。

## 认知负荷

整体为**低至中等负荷**。标题、字段、值和帮助说明有分组；当前区间不需用户记住上一屏数据；键盘与扩展参数折叠，低频信息采用渐进披露。日历格一次呈现多于 4 个日期选择，这是日期任务本身的复杂度。短屏状态下弹层被视口边缘裁切，导致用户要在滚动日历和确认当前可见区域之间分配注意力，是主要额外负荷。

八项清单中：分块、分组、层级、一次一个决定、工作记忆、渐进披露通过；「单一焦点」在短屏弹层被裁切时失败；「最少选择」因同屏月历格数量而失败。共 2 项失败。

## 主要优点

1. **区间结果易核对。** 两个端点和日期色带同时可见，桌面双月能直接比较跨月范围。
2. **窄宽度策略完整。** 375×812 下普通区间和带快捷项的区间都切为单月；快捷项改为顶端横排，两个面板均完整落在视口内。
3. **键盘意图有明确实现。** 代码将焦点移到对应端点日期，窄屏可翻到结束日期所在月份，并在 Escape 关闭后恢复输入焦点；demo 把长说明折叠起来。

## 优先问题

### [P1] 390×375 时弹层锚点未让出可用高度，日历仍被屏幕底边裁切

普通区间弹层稳定态位于 `y=82`，高 359px，底部到 `y=441`，超出 375px 视口 66px；内部内容只比可滚区多 6px，滚轮只能把 `scrollTop` 增加 6px。快捷区间弹层位于 `y=222`，底部到 `y=581`，可见高度只有 153px；弹层内部虽可滚 67px，完整日历仍有大段位于视口外。两种状态的滚轮都由弹层接收、页面 `scrollY` 不变，但弹层位置没有移入屏幕。低高度横屏/嵌入式表单会遮掉可选日期行，造成实际选择困难。  
**建议：** 根据触发器和视口计算上/下可用空间，先把弹层边界放入视口，再让内部日期内容滚动；普通和快捷模式都应覆盖 390×375。  
**建议命令：** `/impeccable adapt`

### [P2] 窄屏演示触发器靠近固定文档顶栏

移动态截图中，自动滚入视口后的起始输入框顶坐标为 `y=33`，而文档移动顶栏覆盖页面上缘；字段标签和部分触发器被顶栏压住，弹层展开后上下文更难辨认。此项属于目标文档页的组合问题，不是 LxDatePicker 自身的日历样式。  
**建议：** 文档演示在滚动定位时给固定顶栏留出间距，避免把活动字段停在顶栏下面。  
**建议命令：** `/impeccable adapt`

### [P3] 桌面快捷弹层紧贴视口底缘

1280×720 下快捷弹层实测底边为 `y=719`，仅剩 1px 余量。内容没有被裁掉，但阴影和边框贴近视口边缘，视觉上略显拥挤。  
**建议：** 为弹层保留稳定的底部安全间距。  
**建议命令：** `/impeccable layout`

## 用户角色风险

- **Jordan，第一次使用日期控件：** 起止输入有独立名称，预设名直白；短屏看不到完整日历时，可能以为部分日期不可选。
- **Sam，键盘或屏幕阅读器用户：** 当前源码包含端点焦点定位、方向键、Enter、Escape 和焦点恢复逻辑；本次没有逐项运行键盘流程或屏幕阅读器，结果不能当作无障碍验收。短屏遮挡同样会造成视觉焦点困扰。
- **Casey，移动用户：** 375×812 的普通/快捷弹层都完整可见；390×375 的两种弹层底部裁切，其中快捷弹层可见区域尤其少，是主要红旗。
- **Alex，熟练用户：** 快捷项与键盘路径可加速操作；短屏选择下方日期需更明确的定位策略。
