## 浏览器与 halo 观察

使用 Playwright 1.58.0 / Chrome 153.0.8010.53 打开 8 个新页面，覆盖桌面与 375px 窄屏、浅色与 HUD 主题、单选与多选聚焦状态。成功完成页面可变性预检并注入 8400 提供的 `detect.js`；8 个页面均返回 HTTP 200，无 page error 或状态码不低于 400 的响应。4174 服务由 PID 18068 提供，8400 helper 为预先运行的 PID 20584；本轮没有停止这两个既有进程。

实测聚焦样式为 2px 外侧 box-shadow halo、1px 实边框、4px 圆角且 `outline: none`。浅色 halo 计算色为 `color(srgb 0 0.376471 0.662745 / 0.15)`，HUD 为 `color(srgb 0.219608 0.741176 0.972549 / 0.15)`。控件外框在桌面为 319×32px，在 375px 视口为 286×32px。八个视图中 halo 均未与聚焦控件 wrapper 相交，也没有遮挡焦点中心；本轮证据未显示 15% halo 造成控件自身边界冲突。

Console overlay 标记摘要：桌面浅色 7、桌面 HUD 175、375px 浅色 5、375px HUD 173。HUD 中大量重复的色彩标记属于 overlay 命中显示，不应直接计作同等数量的独立缺陷。
