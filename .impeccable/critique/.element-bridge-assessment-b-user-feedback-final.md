## Overlay 命中核对

- `layout-transition` 标记 VitePress 的 `.el-tabs__active-bar` 宽度过渡，以及文档 `.container` 的高度/内边距过渡；前者随 tab 切换定位，后者属于文档布局状态变化。这些节点不是多选控件，也没有遮挡其焦点边线。
- 两个 `buried-raster` 命中落在文档代码块的 `.copy` 按钮，属于文档外壳的复制按钮状态，与多选无关；桌面截图中按钮按文档代码区位置呈现。
- `first-viewport-column-overflow` 命中 VitePress 文档 `.container` 的自然长内容与较短的目录列，不是表单控件自身溢出。移动浅色还出现 `positioned child clipped by overflow container`，目标是文档侧栏的 `.container`，不是协同部门 wrapper；多选在 390px 截图中完整可见。
- HUD 状态产生 173 个 overlay 节点，主要来自 `ai-color-palette` 对 HUD cyan/purple 文本和 Element Plus 标签、单选、复选等现有主题元素的命中；overlay 数量不是缺陷数。此轮没有发现 overlay 将“协同部门”的 `.el-select__wrapper` 识别为缺陷目标。
