# LxPageCard 页面容器

用于后台页面中的一组相关数据或设置。组件只提供标题、内容、页脚和加载遮罩，不持有业务数据或请求状态。

## 交互示例

import Basic from '../../src/components/LxPageCard/demo/basic.vue';
</script>

<Basic />

## Props

| 名称          | 类型      | 默认值  | 说明                                                       |
| ------------- | --------- | ------- | ---------------------------------------------------------- |
| `title`       | `string`  | `''`    | 有值时显示标题。                                           |
| `subtitle`    | `string`  | `''`    | 可选副标题。                                               |
| `bodyPadding` | `boolean` | `true`  | 是否为默认插槽内容添加标准内边距。                         |
| `bordered`    | `boolean` | `true`  | 是否显示边框。                                             |
| `loading`     | `boolean` | `false` | 显示遮罩图标并设置 `aria-busy`；请求和错误状态由宿主持有。 |

## 插槽

| 名称           | 位置                   |
| -------------- | ---------------------- |
| 默认插槽       | 页面内容区域。         |
| `header-extra` | 标题区域右侧的操作。   |
| `footer`       | 容器底部的说明或操作。 |

组件没有自定义事件或实例方法。加载期间保留内容布局，根节点设置 `aria-busy="true"`，遮罩通过 `role="status"` 与 `aria-live="polite"` 报告加载状态。

## 使用边界

- `loading` 只呈现视觉遮罩和忙碌语义，不会取消、重试或发起请求。
- 空态、失败提示和下一步操作应由默认插槽中的宿主内容提供。
- 标题使用二级标题语义；页面应按信息层级决定是否传入标题。
