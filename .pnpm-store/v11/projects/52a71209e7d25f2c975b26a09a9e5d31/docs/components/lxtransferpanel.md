# LxTransferPanel 双栏穿梭

把虚拟树中的可选节点与受控已选列表同步展示。组件只处理展示和选择交互，不请求数据，也不判断业务权限。

## Props

| 名称           | 类型                   | 默认值                     | 说明                                                                                                     |
| -------------- | ---------------------- | -------------------------- | -------------------------------------------------------------------------------------------------------- |
| `treeData`     | `LxVirtualTreeNode[]`  | `[]`                       | 左侧待选树。节点使用 `id`、`label`、`children` 和 `disabled`；节点键须唯一。                             |
| `modelValue`   | `(string \| number)[]` | `[]`                       | 受控的已选节点键；可包含暂未加载到当前树中的既有键。                                                     |
| `titles`       | `[string, string]`     | `['待选资源', '已选资源']` | 左右面板标题。                                                                                           |
| `panelHeight`  | `number`               | `380`                      | 面板目标高度，单位 px。左侧树与右侧列表各自滚动。                                                        |
| `maxCount`     | `number`               | `undefined`                | 已选键上限。超限的新增或批量加入整体拒绝；移除和清空仍可用，即使初始值已经超过上限。`0` 表示不允许新增。 |
| `inheritChild` | `boolean`              | `true`                     | 是否保留下级继承授权；组件只回传该开关，不解释后端授权语义。                                             |

## Events

| 事件                  | 参数            | 说明                                                                                               |
| --------------------- | --------------- | -------------------------------------------------------------------------------------------------- |
| `update:modelValue`   | `keys`          | 受控选中键变化，用于 `v-model`。                                                                   |
| `change`              | `(keys, nodes)` | 被接受的选中变化。`nodes` 只包含当前 `treeData` 中能解析的节点；未加载的既有键仍包含在 `keys` 中。 |
| `update:inheritChild` | `value`         | 下级继承开关变化。                                                                                 |
| `clear-all`           | 无              | 用户通过右侧清空或中间全部移除清空非空列表时触发。                                                 |

## 选择规则

- 左侧“全选”和中间向右按钮会加入当前树中所有未禁用节点；上限不足时不做部分写入。
- 左侧“反选”针对当前已加载树中的所有未禁用节点，不受树内搜索结果限制。树外既有键和禁用节点保持原值；选中数量超过上限时拒绝会增加数量的反选。
- 单个禁用树节点不能从左侧新增。右侧删除和清空仍可移除已存在的节点，包括暂时不在当前树中的键。
- `change` 的 `nodes` 不为未加载键构造伪造节点数据。需要完整业务对象时，宿主应按键从自己的数据源解析。
- 左树继承 `LxVirtualTree` 的键盘操作与过滤。组件没有额外 slots 或实例方法；加载、错误和重试状态由宿主包裹处理。
