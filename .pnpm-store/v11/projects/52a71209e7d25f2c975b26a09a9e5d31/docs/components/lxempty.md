# LxEmpty 空态

用于表格、树和穿梭列表等内容区域的无数据提示。默认文案 `暂无数据` 只作兼容兜底，业务调用应说明具体原因，例如尚未配置或当前筛选无结果。需要恢复操作时，由宿主通过 `footer` 插槽传入；loading 和 error 应分别使用对应状态，不要套用空态。

## Props

| 名称          | 类型                     | 默认值         | 说明                                                          |
| ------------- | ------------------------ | -------------- | ------------------------------------------------------------- |
| `description` | `string`                 | `暂无数据`     | 空态描述；较长文案会居中换行。                                |
| `size`        | `'default' \| 'compact'` | `'default'`    | 常规列表或弹窗/抽屉内的紧凑展示。                             |
| `imageSize`   | `number`                 | 按 `size` 决定 | 自定义图标区域的宽高，单位为 px；非法或非正数不覆盖默认尺寸。 |

`imageSize` 同时兼容模板中的 `image-size` 写法，可保留 Element Plus `el-empty` 的同名尺寸用法。

## Slots

| 名称      | 说明                                                       |
| --------- | ---------------------------------------------------------- |
| `default` | 替换默认线稿图标区域；插槽内容按装饰性图标处理。           |
| `footer`  | 描述下方的操作区，适合放置“新建”等由宿主负责的下一步操作。 |

## 视觉与可访问性

默认图标为 64px，紧凑档为 48px；描述分别使用 13px 和 12px 的 `--lx-text-regular` 正文令牌，默认线稿也使用该令牌，避免小字和图形对比度不足。组件根节点使用 `role="status"`，默认线稿图标为装饰性内容；`footer` 中的交互控件沿用宿主提供的语义、名称和键盘行为。组件不添加入场动画。

## Vue3 宿主适配

Vue3 当前有 15 处 `el-empty`。其中两处使用 `:image-size="80"`，迁移时保留相同的属性值；`class` 会透传到组件根节点。业务页面替换和宿主回归仍排在 UI-10 组件闭环及 UI-11 Impeccable 整库审查之后。
