三、研发接口备忘录 (Developer Spec Memo & Vue 3 API)

遵循 TypeScript Strict Mode、Vue 3 SFC Composition API 与 Element Plus 组件设计契约。

npm i @lxui/section-title
TypeScript Props 契约定义 LxSectionTitle.vue 
export interface LxSectionTitleProps {
  /** 标题主文案 (必填) */
  title: string;

  /** 规范视觉形态，默认 'border' */
  variant?: 'border' | 'dashed' | 'plain';

  /** 标题规格大小，默认 14px 'default' */
  size?: 'default' | 'small' | 'large';

  /** 副标题内容，plain 模式下展示在标题后/下方 */
  subtitle?: string;

  /** dashed 模式下可配置前置图标 */
  icon?: string;

  /** 附加数量/状态标签 */
  tag?: string | number;

  /** 标签颜色语义 */
  tagType?: 'primary' | 'success' | 'warning' | 'info';
}
注: 符合公安警务云敏捷大屏与业务后台统一设计基座，已内嵌无障碍 aria-label 自动化匹配。
插槽 Slot & 模板调用示例 ExampleUsage.vue 
<!-- 示例 1: 经典 border 型带 extra 按钮 -->
<LxSectionTitle 
  title="警员在岗档案"
  variant="border"
  tag="一级警督"
>
  <template #extra>
    <el-button link type="primary">修改</el-button>
  </template>
</LxSectionTitle>

<!-- 示例 2: dashed 贯通型带刷新插槽 -->
<LxSectionTitle
  title="设备与网络凭证"
  variant="dashed"
  icon="vpn_key"
>
  <template #extra>
    <el-button text icon="Refresh">重新检测</el-button>
  </template>
</LxSectionTitle>
支持具名插槽：#default, #subtitle, #extra。
