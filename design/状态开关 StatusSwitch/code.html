一、核心开关形态与生命周期矩阵 (Interactive Matrix)

态 A：开启态 (Active)

绿色胶囊底 #67c23a，滑块居右，内嵌加粗白字「开启」，CSS Token: --lx-switch-on

态 B：关闭态 (Inactive)

标准灰底 #909399，滑块居左，内嵌加粗白字「关闭」，严格禁止关闭态误用警示红

态 C：异步 Loading 遮罩态

切换过渡时覆盖微遮罩与 12px 微型旋转 Spinner，防抖防重复触发

态 D：权限不足降级 Tag 态

无权限时不呈现灰死开关，降级为 20px 浅灰点标 LxTag [● 禁用/只读]，杜绝认知困扰

四维交互态实装微标本 (Interactive Matrix Specimens)

三、研发契约与 Vue 3 组件接口 (Developer API & Token Spec)

TypeScript & Tailwind CSS

code Props 参数契约 (LxStatusSwitch.vue)

参数名 类型 默认值 说明
v-model boolean | number false 开关状态，支持兼容 0/1 反向映射
loading boolean false 异步加载遮罩态，附带 12px Spinner
disabled boolean false 禁用原生开关交互
permission string '' RBAC 权限标识码，无权限时自动降级
fallbackTag boolean true 无权限时自动转为 20px LxTag 标本
confirm string | object null 开启二次危险阻断提示弹窗配置

css CSS Design Tokens & 模板用法 

<!-- 示例：公安业务表格行内集成 -->
<LxStatusSwitch
  v-model="row.nodeStatus"
  :loading="row.syncing"
  :permission="'security:node:toggle'"
  :confirm="{
    title: '确认停用该核心节点？',
    message: '停用后将中断跨域警情调度，此操作计入审计。',
    type: 'danger'
  }"
  @change="handleStatusChange(row)"
/>

/* 设计令牌 Design Tokens (DESIGN-SPEC §3) */
:root {
  --lx-switch-height: 20px;
  --lx-switch-width: 42px;
  --lx-switch-thumb: 16px;
  --lx-switch-on: #67c23a;   /* 开启绿 */
  --lx-switch-off: #909399;  /* 统一灰关闭 */
  --lx-shadow-modal: 0 20px 25px -5px rgba(0, 0, 0, 0.2);
}

拍板决策说明：严禁在未经过确认弹窗的情况下直接使用红色表现关闭态。红色仅限全局错误（Error/Alarm）与高危确认弹窗危险按钮。
