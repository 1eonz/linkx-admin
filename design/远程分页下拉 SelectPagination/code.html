传统普通远程 Select 跨页致命痛点

当用户在第 1 页选择了「孙志国(1001)」，翻到第 4 页或输入新搜索词「特警」时，由于返回的数据列表中仅包含当前页结果，组件在 options 里匹配不到 1001 的详细 label，导致触发器内标签瞬间退化为冷冰冰的裸 ID「1001」，甚至被误判定为失效值导致丢失。

LxSelectPagination targetMap 回显锁方案

构建独立于分页列表生命周期的响应式字典缓存 targetMap: Map<id, ItemMeta>。一旦选中，该元数据即刻存入锁住。后续无论远程分页列表如何被清空、换页、或搜索结果无匹配，触发器永远优先从 targetMap 中精准提取格式化后的结构化 Label。

lock targetMap 稳定回显态 (翻页至第 4 页，历史 3 项完全锁定)：

<!-- 业务使用端 template -->
<LxSelectPagination
  v-model="selectedPoliceIds"
  :remoteMethod="fetchPolicePaging"
  valueKey="policeCode"
  :labelKey="(item) => `${item.name} (${item.policeCode})`"
  :targetMap="historyPoliceCache"
  :maxCollapseTags="2"
  :debounce="300"
  placeholder="指派涉案警员（支持工号/姓名分页检索）"
/>

const selectedPoliceIds = ref(['POL-005882', 'POL-001042'])
const historyPoliceCache = ref({
  'POL-001042': { name: '陈明远', policeCode: 'POL-001042' }

// 分页拉取函数
async function fetchPolicePaging(query, page) {
  const res = await api.getPoliceList({ query, page, size: 20 })
  return {
    list: res.data.records,
    total: res.data.total,
    hasMore: res.data.current * 20 < res.data.total
  }
}
