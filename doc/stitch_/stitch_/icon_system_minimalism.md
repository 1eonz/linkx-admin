# 警务业务协同后台 (LinkX Admin) 图标减法与通用图标体系落地规范

> **执行原则**：克制收敛、减法优先、通用统一、纯文本优先  
> **设计系统基准**：`{{DATA:DESIGN_SYSTEM:DESIGN_SYSTEM_1}}` (Police Command & Operations System)  
> **制定日期**：2026-09-21

---

## 1. 核心减法原则（Where to Remove Icons）

1. **表格行内操作栏（Actions Column）**：
   - 彻底废除图标！杜绝行内「✏️ 编辑」「🗑️ 删除」「👁️ 详情」「🔑 授权」。
   - **全面采用 13px/14px 纯文字按钮（Text Buttons）**：次级文字色 `#409EFF`，危险删除色 `#F56C6C`，操作项水平间距固定 `12px`。
2. **表单输入框与下拉筛选器**：
   - 移除用户名、密码、分局、排班类型、关键词等输入框内的修饰性前缀图标（如小人头、锁、小房子等）。
   - 依靠清晰的顶部/左侧 Label 和浅灰 Placeholder 表达意图；
   - 仅保留原生功能必需的：下拉倒三角（`▾`）、日期选择器、文本清除按钮（`×`）。
3. **表格状态列（Status Column）**：
   - 移除复杂拟物状态图标，统一采用 **直径 6px 的纯色实心圆形状态微灯（Status Dot）**：
     - 正常/在线：`#67C23A` (Green)
     - 告警/异常：`#F56C6C` (Red)
     - 预警/待办：`#E6A23C` (Orange)
     - 离线/停用：`#909399` (Gray)
4. **二级/三级业务菜单**：
   - 纯文字缩进层级展示，彻底剔除二级细分菜单前生造的微缩图标。

## 2. 全系统极限收敛的「8 组高频通用矢量图标集」

全站禁止随意引入第三方外部字体图标库，统一收敛为 **8 组 16px/14px 纯矢量 SVG 图标**，描边统一 `1.5px` 或 `2px`：

| 分类序号 | 通用图标类别 | 符号/形态 | 标准尺寸与间距 | 唯一允许使用场景 |
| :--- | :--- | :--- | :--- | :--- |
| **01** | **检索类 (Search)** | 🔍 矢量放大镜 | 14×14px, 与文字间距 6px | 搜索/查询主要按钮 (`SearchButton`) |
| **02** | **重置/刷新 (Refresh)** | 🔄 环形双向箭头 | 14×14px, 与文字间距 6px | 筛选重置按钮、表格右上角数据手动刷新 |
| **03** | **新增类 (Plus)** | `+` 细线十字加号 | 14×14px, 与文字间距 4px | 顶层主要动作按钮（如 `+ 新增排班`、`+ 新增服务`） |
| **04** | **危险与清除 (Close/Warn)** | `×` 细线叉号 / ⚠️ 警示三角 | 14×14px / 16×16px | 弹窗右上角关闭、Tag 移除、表单校验报错提示 |
| **05** | **方向导航 (Caret/Chevron)** | `▾` 下三角 / `›` 右折角 | 12×12px / 14×14px | 下拉框展开、菜单折叠/展开、分页翻页 |
| **06** | **数据流向 (Arrow/Transfer)**| `→` 细箭头 / `>` 穿梭符号 | 14×14px | 穿梭框移入/移出、全链路日志单向流转 |
| **07** | **全局系统 (System Chrome)** | 🔔 预警铃铛 / ⛶ 全屏 / 🎙️ 麦克风 | 16×16px | 顶栏右侧全局快捷监控区、语音对讲状态 |
| **08** | **数据交换 (IO Exchange)** | 📥 导出下载 / 📤 上传导入 | 14×14px | 报表导出 Excel、底图/配置上传 DropZone |

## 3. 代码与渲染规范（杜绝缺失与方框）

- **禁止引入 `@font-face` 外部 WebFont**，防止网络波动或未加载完成时出现空白方框；
- 所有通用图标均统一封装为 SVG Symbol 或内嵌 `<svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2">`，跟随父级字体色彩，100% 杜绝渲染失败；
- 按钮内统一配置 `display: inline-flex; align-items: center; justify-content: center; gap: 6px;`。
