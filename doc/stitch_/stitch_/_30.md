## 2. 界面统一组件库全景归类 (Component Catalog)

根据现有原型 (`linkx-admin-prototype.html`)、PRD (`PRD-vue3-reconstruction.md`) 以及架构设计 (`ARCHITECTURE-vue3.md`)，将系统目前已展示或潜在待落地渲染的所有组件分为 **8 大类、36 个基础与业务复合组件**：

```
                    LinkX Admin 组件全景架构
                               │
 ┌──────────────┬──────────────┼──────────────┬──────────────┐
 │              │              │              │              │
导航与框架     布局与容器     数据展示       通用输入与表单   交互反馈
(Navigation)   (Layout)       (Data Display) (Form Inputs)   (Feedback)
 │              │              │              │              │
 ├─ AppShell    ├─ PageCard    ├─ ProTable    ├─ SearchInput ├─ Toast
 ├─ PureSidebar ├─ SplitLayout ├─ StatusBadge ├─ RangePicker ├─ FormErrorAlert
 ├─ NavBar      └─ StatGrid    ├─ StatusSwitch├─ SelectTree  ├─ ConfirmModal
 ├─ Breadcrumb                 ├─ LogList     ├─ VirtualList └─ SlideDrawer
 └─ StandardTabs               └─ KeyValueCard└─ UploadDrop  
```

### 类别一：系统导航与壳层组件 (Navigation & Shell)
1. **`AppShell`（系统总壳层）**：包含固定左侧导航栏、顶栏、面包屑与主体内容区。
2. **`PureSidebar`（方案二战术纯文字侧边栏）**：
   - 展开态（宽度 `230px`，纯文字层级树，无分组杂质，等高 `64px` Logo 区）；
   - 收起态（宽度 `54px` / `64px`，微缩战术状态轨 + Hover 悬浮浮层）。
3. **`StandardTabs`（规范卡片滑动 Tab）**：
   - 高度固定 **48px (`h-12`)**；
   - 激活态字体色 `#409EFF`、字重 600，底部固定 **2px 高度纯色滑动指示条**；
   - 常规态 `#606266`，带胶囊数量徽标（如 `6 活跃`、`124`）。
4. **`Breadcrumb`（战术路由面包屑）**：
   - 路径导航（如 `警务业务协同平台 / 三方对接 / 服务配置`）；
   - 右侧集成等宽路由徽标（如 `路由: /thirdParty/southInterface`）。
5. **`TopNavBar`（顶栏监控组件）**：
   - 包含网关连接状态灯（`18/20 节点`）、今日吞吐调用量（`1,489,204 次`）、全屏切换、操作员头像下拉菜单。

### 类别二：搜索与数据筛选组件 (Search & Filters)
6. **`SearchFilterPanel`（一体化搜索筛选面板容器）**：
   - 背景色 `#f8fafc`，边框 `1px solid #ebeef5`，圆角 `6px`，padding `16px 20px`；
   - 内部控件行间距 `12px`，统一底边距 `16px`。
7. **`StandardInput`（统一输入框）**：
   - 高度统一为 **36px (`h-9`)**，边框 `#dcdfe6`，圆角 `4px`，Focus 状态亮起 `#409EFF` 阴影。
8. **`StandardSelect`（统一单选/多选下拉框）**：
   - 高度统一为 **36px**，右侧带平滑旋转下三角箭标。
9. **`ButtonActionGroup`（统一操作按钮组）**：
   - 主操作按钮（`#409EFF` 蓝底白字，配放大镜或“+”矢量图标）；
   - 次级重置按钮（白底灰框，配重置旋转图标）；
   - 业务动作按钮（如 `+ 新增服务对接`、`批量授权权限`、`导出配置清单`）。

### 类别三：数据表格与列组件 (Table & Data Grid)
10. **`StandardTable`（统一企业级数据表格）**：
    - 表头高度 **48px**，浅冷灰背景 `#f5f7fa`，字重 600，字体颜色 `#606266`；
    - 数据行高 **52px**，底边线 `1px solid #ebeef5`，悬浮行高亮 `#f8faff`；
    - 全列强制配置 `white-space: nowrap`，彻底消除单字折行与纵向挤压。
11. **`StatusSwitch`（内嵌文字状态开关）**：
    - 规格 **56px × 24px**，圆角 **12px**；
    - **开启态**：高饱和 `#409EFF` 轨道，左侧显示居中文本「**开启**」，右侧为 18px 纯白圆形滑块；
    - **关闭态**：浅灰 `#dcdfe6` 轨道，右侧显示「**关闭**」，左侧为圆形滑块；
    - 图文绝对空间隔离，100% 杜绝文字滑块重叠。
12. **`ProtocolBadge`（应用协议/类型徽章）**：
    - 针对 `RESTful接口`、`JDBC直连库`、`Kafka消息队列`、`MQTT物联网`、`GB28181流媒体` 采用专属的低饱和度柔和背景与边框色彩（如紫、橙、蓝、绿）。
13. **`CodeSlot`（IP/端口代码展示槽）**：
    - 针对 `10.128.42.19 : 8080`、`SVC_POLICE_TASK_V3` 采用等宽字体（Menlo, Consolas）与浅灰底槽。
14. **`StandardPagination`（统一右对齐分页器）**：
    - 高度统一 **32px**，右对齐；
    - 包含记录总数（`共 14 条记录`）、每页条数切换下拉（`10条/页`）、高亮数字页码（激活为 `#409EFF` 蓝底白字）、以及跳转跳页器。

### 类别四：数据录入与高级选择器 (Form Inputs & Selectors - 待落地/规划组件)
15. **`SelectTreeLazy`（组织架构树懒加载选择器）**：支持异步加载市局-分局-派出所-专班层级。
16. **`VirtualCheckboxList`（海量警员/设备虚拟滚动多选器）**：在千人以上警员绑定时防掉帧。
17. **`DateRangePicker`（勤务排班日期区间选择器）**：支持白班、夜班周期快选。
18. **`UploadDropZone`（底图与文档拖拽上传区）**：支持 GIS 切片包、知识库文档上传。
19. **`CoordinatePicker`（GIS 经纬度拾取器）**：支持高德/天地图/WGS84 坐标点击拾取与反填。

### 类别五：交互反馈与弹窗体系 (Feedback & Modals)
20. **`FormErrorBanner`（全局表单提交错误警示条）**：浮动于顶部居中，橙红底色，醒目标注“表单必填项校验提示态”。
21. **`FormModal`（标准业务新增/编辑弹窗）**：模态阴影遮罩，顶部标题 + `×` 关闭，内部两列对齐表单（必填项标红 `*`），底部「取消」/「确定」按钮。
22. **`ConfirmDialog`（危险删除/解绑确认框）**：居中二次确认弹窗。
23. **`DetailDrawer`（侧滑详情/日志抽屉）**：从右侧滑出，承载全链路服务日志追溯、执行详情。
24. **`ToastNotification`（轻量全局通知）**：操作成功/失败轻提示，1.6 秒自动隐藏。

### 类别六：统计看板与监控卡片 (Dashboard & Metrics Cards)
25. **`SecurityChannelCard`（警务专网加密通道状态卡）**：国密 SM4 状态、硬件密钥有效期指示。
26. **`FlowLimitCard`（流量控制与限流防护卡）**：令牌桶动态进度条、QPS 负载显示。
27. **`AuditLogCard`（全链路服务日志追溯卡）**：24小时熔断次数、调用日志看板跳转。
28. **`MetricHeroCard`（态势数据统计大卡片）**：在岗警力、流转警情、边缘节点核心数值与环比趋势线。

## 3. 全页面统一改造映射表 (Page Migration Mapping)

按照基准页 `{{DATA:SCREEN:SCREEN_2}}`，所有业务页面将统一对齐如下要素：

| 业务页面 | 改造前痛点 | 统一标准改造要点 |
| :--- | :--- | :--- |
| **三方对接 (`/thirdParty/*`)** | 原部分页面无灰色搜索容器，Tab 缺失或样式漂移 | 严格套用 `SCREEN_2` 标准：48px Tab + 浅灰圆角搜索面板 + 52px 行高表格 + 内嵌文字 Switch + 底部三大监控卡片 |
| **多节点管理 (`/nodeManage/*`)** | 弹窗与表格重叠穿透，Switch 文字与滑块遮挡 | 统一收敛为标准 Tab 导航，去除多余弹窗穿透，Switch 采用 56×24px 图文隔离轨道 |
| **排班管理 (`/scheduling/*`)** | 日历与列表筛选区控件散乱，校验错误阻断页面 | 统一 48px 日历/列表 Tab 切换，搜索区收敛为 `#f8fafc` 容器，表单报错仅在弹窗内高亮标红 |
| **位置管理 (`/location/*`)** | 左侧组织树与右侧表格高度与间距不对齐 | 统一右侧搜索与数据表格为 48px 表头/52px 行高，左侧组织树采用标准化浅灰底色 |
| **通知预警 (`/notification/*`)** | 逾期预警与无人值守 Tab 样式与底线漂移 | 统一为标准下划线滑动 Tab，配备圆角状态标签与操作按钮组 |
| **权限中心 (`/authority/*`)** | 组织树与用户列表按钮样式杂乱 | 规范化顶栏 Tab、统一操作按钮为 36px 高度、统一表格行高与复选框样式 |
| **系统配置 (`/baseData/*`)** | 分类 Chip 胶囊与表格层级排版各异 | 统一搜索区与标准表格列宽，参数键值采用等宽代码背景槽展示 |

## 4. 交付总结与后续落地

本规范确立了全系统的绝对统一视觉标准。后续无论是新增业务页（如三方应用管理、北向接口管理）还是编辑现有页面，均必须严格从上述 **36 个标准组件** 中组合派生，彻底保障系统从底层交互逻辑到像素级视觉呈现的一致性。
