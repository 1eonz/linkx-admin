# Stitch 设计任务 Prompt 手册（可直接复制使用）

> 日期：2026-09-22 | 用途：在 Stitch 中继续 LinkX Admin 的设计工作（已有 39 页设计稿，见 `doc/stitch_/stitch_/`）
> 配套需求：组件缺口清单见 `doc/lx-ui/COMPONENT-STYLE-INTERACTION.md`，图标清单见 `doc/lx-ui/ICON-DESIGN.md`
> 使用姿势：新会话/新项目先发【第二部分】建立风格上下文 → 按任务复制【第三部分】对应 prompt → 需要「长得像已有页面」时按【第四部分】传参考文件 → 生成稿按【第五部分】验收

---

## 一、使用流程（4 步）

```
① 新会话开场 → 复制【第二部分】整段发送
② 发具体任务 → 复制【第三部分】对应 prompt（一次一个任务，别混发）
③ 要延续既有设计 → 按【第四部分】上传对应 screen.png（或粘贴 code.html）
④ 生成结果 → 按【第五部分】清单验收，不合格把问题点追加发回改
```

**两种工作模式**：
- **原项目延续**（推荐）：在原来生成 39 页的 Stitch 项目里继续，风格自动延续，可跳过②中重复的风格描述
- **新会话/新项目**：必须先发【第二部分】开场上下文，否则生成的风格会漂移

## 二、开场上下文（每次新会话必发，整段复制）

```text
你正在为「LinkX Admin 公共安全管理后台」继续设计 UI。这是一个公安行业的
管理系统（GB 公共安全视觉规范），已有 39 页设计稿，现在需要补充新的组件与图标。

【设计语言】
- 整体风格：专业、克制、高信息密度的政企管理后台；亮色内容区 + 深色 HUD 风格侧边栏
- 布局骨架：左侧深色导航栏（宽 252px）+ 顶部 56px 白色工具栏 + 内容区浅灰底（#f0f2f5）+ 白色卡片
- 中文字体：HarmonyOS Sans SC / PingFang SC；界面文案全部中文

【设计令牌（严格遵守，不要发明新值）】
- 主色：#0060a9（hover #00508f）；主色浅底 #ecf5ff
- 功能色：成功 #67c23a / 警告 #e6a23c / 危险 #f56c6c / 中性 #909399（各自配 95% 浅底：#f0f9eb / #fdf6ec / #fef0f0 / #f4f4f5）
- 文字：标题 #1d2129 / 正文 #4e5969 / 辅助 #86909c / 占位 #c9cdd4
- 边框：外框 #e4e7ed，行分隔 #ebeef5；卡片底 #ffffff
- 圆角三档：2px（标签）/ 4px（按钮、输入框、卡片）/ 8px（弹窗、抽屉）
- 阴影三档：卡片 0 1px 4px rgba(0,21,41,.08) / 浮层 0 2px 12px rgba(0,0,0,.1) / 弹窗 0 4px 16px rgba(0,0,0,.15)
- 控件高度：标准 32px（小 28px / 大 40px）；表格行高 44px，表头 40px 灰底 #f5f7fa
- 深色侧边栏：底 #0c1424，激活文字 #7dd3fc（sky-300），激活竖条 #38bdf8 带 8px 光晕

【产出要求】
- 单文件 HTML + Tailwind CSS，可直接在浏览器预览
- 关键尺寸（间距/圆角/字号）用 HTML 注释标注
- 状态完整：默认/hover/disabled/错误态都要有
- 使用中文文案，不要用 Lorem ipsum
```

## 三、任务 Prompt 库（按需复制，一次发一个）

### A. 组件设计（缺口清单）

#### A1. 检索面板 SearchBar（P0 最高优先）

```text
设计一个列表页顶部的检索面板（SearchBar），嵌入在白色卡片内：
- 字段区：4 列网格布局，字段间水平间距 16px、垂直 8px；每个字段 = 12px 灰色
  label 在上 + 32px 高输入控件在下
- 字段示例：关键字搜索框（220px，左侧内置放大镜图标）、组织树选择器（输入框+
  展开箭头形态）、日期范围选择器（双输入框）、状态下拉选择
- 按钮区：右下角独立一行，「查询」主色实心按钮 + 「重置」白底描边按钮，水平排列
- 展示两种状态：字段 ≤4 个时的单行完整形态；字段 >8 个时的折叠形态（首行 4 个
  字段 + 查询/重置按钮 + 右侧「展开 ▾」文字链接）
- 输入框规格：32px 高、4px 圆角、边框 #dcdfe6、聚焦态主色边框 + #ecf5ff 外发光环
```

#### A2. 状态开关 StatusSwitch（P0）

```text
设计一个表格行内使用的状态开关组件：
- 胶囊滑块形态：高 20px、宽约 40px、圆角 full，滑块内嵌文字「开启/关闭」
- 开启态：#67c23a 绿底白字；关闭态：#909399 灰底白字
- 展示三种使用场景：
  1. 表格「状态」列内的行内开关（正常 + loading 转圈遮罩态）
  2. 权限不足禁用态：显示为浅灰「禁用」小标签（tag 形态），不是灰色开关
  3. 危险操作提示场景：关闭开关前弹出确认框（512px 居中，红色警示图标 +
    标题「确认停用该节点？」+ 正文说明后果 + 红色实心「确认停用」按钮 + 白底「取消」）
```

#### A3. 按钮体系（P0）

```text
设计完整的按钮规范展示页：
- 三种尺寸：small 28px / default 32px / large 40px，各含左右 padding 16px
- 四种形态 × 三态（默认/hover/disabled）：
  1. 主按钮：#0060a9 实底白字（hover #00508f）
  2. 次按钮：白底 + 1px #dcdfe6 边框 + #4e5969 文字（hover 边框和文字变主色+浅蓝底）
  3. 危险按钮：#f56c6c 实底白字（用于批量删除）
  4. 文字链接按钮：主色文字透明底（hover 浅蓝底圆角）
- 附使用场景示例：工具栏（新增主按钮 + 批量删除危险按钮 + 导出次按钮并排）、
  弹窗底部（取消次按钮 + 确认主按钮右对齐）
```

#### A4. 表单控件八件套（P0）

```text
设计表单控件规格展示页，统一视觉（32px 高、4px 圆角、边框 #dcdfe6）：
1. 文本输入框：默认/聚焦（主色边+#ecf5ff 外环）/错误（红边红字提示 11px + 浅红底）
2. 下拉选择器：触发器 + 展开的下拉面板（选中项主色文字、hover 浅灰底、圆角 4px、
   阴影 0 2px 12px rgba(0,0,0,.1)）
3. 单选组 / 4. 复选组：选中态主色
5. 数字输入器：右侧上下调节箭头
6. 日期选择器：范围型双输入 + 展开的日历面板
7. 开关 / 8. 文本域 textarea（3 行高）
每个控件配 12px 灰色 label 上置 + 必填红色星号，错误态展示红字提示文案
```

#### A5. 上传拖拽区 Upload（P1）

```text
设计文件上传拖拽区组件：
- 拖拽区：2px 虚线边框 #dcdfe6、8px 圆角、高 120px、浅灰底
- 中心内容：40px 上传图标（主色）+ 主文案「点击或拖拽文件到此处上传」
  + 副文案「支持 .xlsx / .csv 格式，单文件不超过 10MB」（12px 灰字）
- 三个状态：默认 / 拖拽悬停（虚线变主色 + 浅蓝底）/ 上传中（进度条 + 百分比）
- 下方文件列表行：状态点（上传中蓝/成功绿/失败红）+ 文件名 + 大小 + 删除 X
```

#### A6. 指标卡 MetricCard（P1）

```text
设计数据指标卡片（用于详情抽屉/仪表盘）：
- 白底卡片、4px 圆角、卡片阴影；内部：13px 灰色标题（如「今日警情总数」）
- 大数值：24px 加粗等宽数字字体（如 1,247）+ 右侧 13px 单位「件」
- 数值语义色：正常主色 / 警告 #e6a23c / 危险 #f56c6c
- 右上角浅底小标签（如「环比 +12.4%」）
- 底部进度条：高 6px、圆角 full、槽 #ebeef5、填充主色
- 展示 3 张卡并排：在线率 99.9%（绿）/ 平均响应 4.2s（警告）/ 高危未处理 18（红）
```

#### A7. 详情描述行 Descriptions（P1）

```text
设计详情页键值对描述行组件（用于右侧详情抽屉内）：
- 行式两端对齐：左侧 13px 灰色 label、右侧 13px 深色 value
- 行高 32px、行间 1px #ebeef5 分隔线
- 展示 8 行示例（姓名/警号/联系电话/所属组织/角色/状态/创建时间/备注）
- 特殊值样式：警号用等宽字体浅灰底代码槽（2px 圆角）；状态列 = 6px 绿点+「在线」文字
- 附两列布局版本（label-value 双列网格）
```

#### A8. 区块标题 SectionTitle（P1，保留三变体）

```text
设计区块标题组件，三种变体：
1. border 型：左侧 3px 主色竖条 + 14px 加粗标题 + 右侧可选操作按钮（如「编辑」文字链接）
2. dashed 型：标题 + 下方通栏 1px 虚线分隔
3. plain 型：纯文字标题 + 12px 灰色副标题
每个变体配右侧 extra 区示例（刷新按钮/更多文字链接）
```

#### A9. 远程分页下拉 SelectPagination（P1）

```text
设计远程搜索分页下拉选择器（选人/选设备场景，数据量大需远程分页）：
- 触发器：32px 输入框，多选时内部显示已选 tag + 「+2」折叠计数 + 展开箭头
- 展开面板：顶部搜索框（内置放大镜）+ 结果列表（每行 32px：姓名 + 12px 灰色工号）
- 列表底部：滚动加载态（转圈 +「正在加载更多」）和终态（灰色「已加载全部」）
- 重点展示：已选项不在当前页时，触发器中仍正确显示姓名（回显能力）
```

#### A10. 虚拟滚动树 + 双栏穿梭（P2）

```text
设计两个树相关组件：
1. 大数据量虚拟滚动树：树节点行高 32px、缩进 16px/级、展开箭头、复选框、
   顶部搜索过滤框；展示 100+ 节点滚动形态 + 细滚动条 4px
2. 数据权限双栏穿梭：左栏虚拟树 + 顶部「全选/取消」操作；右栏已选列表
  （行 = 名称 + 删除 X）+ 底部「已选 N 项」计数；两栏等高 max 400px 内部滚动
```

## 四、附件对照表（何时上传什么）

> Stitch 支持上传图片作参考。**要新组件「长得像已有页面」时，先传对应参考图再发 prompt**（上传后补一句：「延续参考图的整体风格与密度」）。

| 任务场景 | 上传的参考文件 | 说明 |
|---|---|---|
| 任何延续全局风格的任务 | `doc/stitch_/stitch_/component_library_showcase/screen.png` | 组件标本库，风格最全 |
| 列表页/表格类组件 | 任选一页列表类设计的 `screen.png`（翻 `doc/stitch_/stitch_/_N/` 目录确认内容） | 39 页中列表页较多 |
| 弹窗/表单类 | `_26/screen.png` | 已确认是 672px 双列表单弹窗 |
| 排班日历类 | `_21/screen.png` 或 `_24/screen.png` | 日历网格设计稿 |
| 侧边栏/导航相关 | `doc/stitch_侧边栏/stitch_/_2/screen.png` | expanded 完整形态（_1 是 rail 窄条） |
| 大屏 HUD 深色类 | `hud_1/screen.png`、`hud_2/screen.png` | 指挥大屏 |
| 地图 GIS 类 | `gis_1/screen.png`、`gis_2/screen.png` | 地图底图设计 |
| AI 智能体类 | `ai_1` ~ `ai_4/screen.png` | 智能体专题页 |
| 图标风格对齐 | 粘贴 `doc/stitch_/stitch_/icon_system_minimalism.md` 内容或现有图标页 | 图标体系说明 |

**code.html 的用法**：把某一页的 `code.html` 内容直接粘贴到 Stitch 对话中（「以下是已有组件的代码，请延续相同的风格与 class 习惯」），比截图更精确，适合做组件的精细延展。

## 五、生成结果验收清单

拿到 Stitch 生成稿后逐项检查（不合格的项直接追加发给 Stitch 改）：

| # | 检查项 | 标准 |
|---|---|---|
| 1 | 主色 | 只有 #0060a9 一个主色，没有出现第二个蓝 |
| 2 | 圆角 | 只出现 2/4/8px 三档，没有 12px（Toast 除外）/16px 杂值 |
| 3 | 控件高度 | 32px 为主（28/40 为明确的小/大档） |
| 4 | 文字色 | 四级灰阶 #1d2129/#4e5969/#86909c/#c9cdd4，没有第五种灰 |
| 5 | 状态色 | 深浅成对（图标/文字用深色，底用浅色），没有深底配深字 |
| 6 | 图标 | stroke 1.5 线性、单色、24×24 网格内 |
| 7 | 文案 | 全中文真实业务文案，无 Lorem ipsum / 无英文按钮 |
| 8 | 状态完整 | hover / disabled / 错误态是否齐全（任务里要求的） |
| 9 | 阴影 | 只有三档阴影，卡片不发光 |
| 10 | 中文字号 | 主体 13px 表格/14px 正文，标题不超 16px |

## 六、产出回收约定

Stitch 生成的 `code.html` 按「组件名-日期」归档到 `doc/stitch_/stitch_/新批次目录/`，
并在本文档第四部分补充登记（哪页是什么组件），保证后续任务能找到参考。
