# 价察 · 前端设计规范（design.md）

- 版本：v1.0（2026-10-10）
- 依据：PRD v1.1、架构设计方案 v1.1、交互原型 `index.html`
- 适用范围：Web Admin 前端（桌面优先；快速录入页移动端优先）
- 说明：原型 `index.html` 是视觉与布局的规范来源，本文档将其令牌化并补齐 PRD v1.1 新增页面的设计；demo 中与 PRD 口径冲突处按第 10 节修正表执行

---

## 1. 设计原则（产品口径 → 界面规则）

| 产品原则（PRD） | 界面落法 |
| --- | --- |
| 直播间公开报价为主价格 | 主价格用展示字体（Display）大字号呈现；满减、赠品、优惠始终位于次级信息区 |
| "已收录最低"而非"历史最低" | 文案统一为"已收录最低报价"，旁必带样本数与数据范围 |
| 价格评价与购买意愿分开 | 两个独立列 / 两组独立标签（价格状态 ≠ 我的意愿），永不合并列 |
| 不以颜色为唯一涨跌表达 | 箭头（↑↓→）+ 文字金额 + 颜色三重编码 |
| 标称总价是口径、有效价是参考 | 对比类页面双价并列展示："标称 ¥399 · 有效 ¥359（免定金）" |
| 提示层不改口径 | 折算单价、系统比较标签均带"提示"标识，可手动修改，改后不影响统计 |
| 空态诚实 | 四种空态（无数据 / 无有效报价 / 筛选无结果 / 缺少同期数据）文案严格区分 |
| DRAFT 可比但不入统计 | 对比页草稿行灰显 + "草稿"标签；统计数字永远排除 |

| `--line` | `#dfe5de` | 分隔线 / 边框 |
| `--line-strong` | `#c9d3ca` | 控件边框 |

**语义色**（与 demo 一致，禁止新增近似色）

| --- | --- | --- | --- |

**标签（Tag）色彩语义映射**（全局唯一映射，不得混用）

| 色 | 标签示例 |
| --- | --- |
| teal | `有效` `已达目标价` `价格更低` `值得关注` `已收录最低` |

| amber | `待核实` `草稿`（灰显场景除外）`再等等` `等降价` `价值下降` `需人工判断` |
| plum | `已购买` `已归档` `已过期` |
| neutral | `观察中` `暂不考虑` `条件报价` |

### 2.2 字体

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `--font` | `"Noto Sans SC","Microsoft YaHei",system-ui,sans-serif` | 界面文字，基准 15px |
| `--display` | `Georgia,"Noto Serif SC","Songti SC",serif` | 价格数字、KPI 数值、大标题（h2/决策卡标题） |

字号阶梯：32（页标题）/ 27–30（商品名 / 决策标题）/ 23（分类卡）/ 19–20（品牌名）/ 17（h3）/ 15（正文）/ 13（表格 td / lead）/ 12（field label / 辅助）/ 11（th / tag / help，th 加 `letter-spacing:.07em; text-transform:uppercase`）

### 2.3 圆角 / 阴影 / 间距

- 圆角：`--r-sm:10px`（按钮/输入框/chip）、`--r-md:16px`（卡片）、`--r-lg:24px`（大图块）、`999px`（胶囊：搜索框/标签/头像）
- 阴影：卡片 `0 5px 18px rgba(24,43,32,.025)`；浮层 `--shadow:0 18px 45px rgba(24,43,32,.08)`
- 间距基准：卡片内边距 22px；栅格 gap 13–20px；内容区左右 42px（窄屏 26px，移动 16px）

### 2.4 关键尺寸

| 项 | 值 |
| --- | --- |
| 侧栏宽度 | 244px（≥1051px）/ 205px（721–1050px）/ 移动端转为顶部横向导航 |
| 内容区最大宽 | 1440px 居中 |
| 控件高度 | 输入 44px / 按钮 42px / 小按钮 34px / 触控目标（移动端）≥44px |
| 顶栏 | sticky，高约 80px，`backdrop-filter:blur(16px)` |

## 4. 通用组件规范

### 4.1 按钮 `.btn`

- 变体：默认（surface 底 + line-strong 边）/ `primary`（coral）/ `ghost`（透明）/ `small`（34px）
- 状态：hover（加深边框 / coral-dark）/ focus-visible（3px `rgba(232,102,79,.35)` 外描边）/ loading（spinner + 禁用）/ disabled
- 规则：提交类请求期间必须 loading + 禁用；主操作每屏唯一 primary

### 4.2 卡片

| 组件 | 规范 |
| --- | --- |
| `.card.pad` | 基础白卡：1px line 边框、16px 圆角、内边距 22px、`card-head`（标题 + 说明 + 右侧操作） |
| `.kpi` | KPI 卡：高 ≥126px，muted 标签行 + 图标块（28px soft 底）、Display 数值 30px、meta 12px |
| `.metric-card` | 深色卡（`--ink` 底反白）：用于"已收录最低报价"等单一关键口径，含 mini-line 进度示意 |
| `.decision-card` | 总览 hero：teal-soft 底 + 同心圆装饰，coral 强调数字 |
| `.decision-panel` | 商品页侧栏：米底（#fff9f0），价格结论 + 目标价/意愿行 + 主操作 |
| `.category-card` | 矩阵页分类卡：tag + Display 标题 + sparkline |

### 4.3 标签 `.tag`

胶囊、11px/800、色语义见 2.1。规则：状态列只允许一个主标签；辅助信息（如 `第一波预售`）用 neutral 小标签并排。

### 4.4 表格 `.table`

- th：11px 大写字距；td：13px；行 hover `#fafcf9`；`.current` 行浅绿高亮（`#eef7f2`）标注"当前/最低"行
- 首列商品单元：`.product-cell`（36px 缩写块 `.product-thumb` + 名称 + muted 副行：规格 · 直播间）
- **状态行的视觉编码**：DRAFT 行整体 `opacity:.55` + amber `草稿` 标签；PENDING_VERIFY 行 amber `待核实` 标签；过期报价在状态列加 plum `已过定金期`
- 列宽超屏时 `.table-wrap` 横向滚动，禁止压缩列

### 4.5 筛选与切换

| 组件 | 行为 |
| --- | --- |
| `.filter-chip` | 单选组（同组互斥），active = teal-soft 底 + teal 字 + 边框 |
| `.event-tab` | 届次切换（2026 618 / 2025 双十一…），active = ink 底反白 |
| `.chart-toggle` | 图表视图切换（近 3 年 / 按活动），active = 浅灰底 |

### 4.6 表单 `.field`

- label 12px/800，必填以 coral-dark `*` 标注；help 文案 11px muted（口径提示常驻，如"这是主价格。不要先扣个人红包"）
- 输入 44px、10px 圆角、`#fbfcfa` 底；校验错误：边框 coral-dark + 下方错误文案（指明字段）
- 布局：`.form-grid` 两列，`.field.full` 跨列；弹窗关闭 / 保存成功后 `resetFields` 清校验

### 4.7 赠品动态列表（PRD 7.3，demo 未含，新增组件）

```
赠品 (2)                                    [+ 添加赠品]
┌ 名称[同款正装] 分类(●同款正装○同品小样○其他) 数量[1]瓶  [删除] ┐
├ 名称[小样]     分类(○同款●同品小样○其他)     净含量[50]ml [删除] ┤
└──────────────────────────────────────────────┘
```

- 分类驱动联动：`同款正装` → 必填数量（折算参与）；`同品小样` → 必填净含量（归一提示）；`其他` → 仅展示
- 常驻 help："套装内容物不是赠品，请在规格组合说明中记录"
- 同名赠品再次添加 → 提示"合并数量为 2"（非阻断）

### 4.8 定金组（新增组件）

字段：`定金` `尾款` `免定金`（checkbox）。联动规则：

- 填定金 → 尾款必填，校验 `定金 + 尾款 = 报价`，不一致即时报错
- 勾选免定金 → 预览面板实时显示 `有效价 = 报价 − 定金`，并显示 coral `免定金` 标签
- 只填定金无法保存为有效报价 → 保存按钮旁 status 提示

### 4.9 预览面板 `.preview`（sticky top 92px）

右侧实时预览，随表单输入更新：商品/规格、直播间 · 活动、**标称总价**（Display 36px）、有效价（免定金时双价显示）、折算单价（有同款赠品时）、赠品摘要、状态（待核实）。底部附"录入原则"卡。

### 4.10 浮层

| 组件 | 规范 |
| --- | --- |
| `.toast` | 右下角；成功 teal（`#f0faf6` 底）、警告 amber、错误 coral；2.5s 自动消失；`role="status" aria-live="polite"` |
| Modal | 居中、surface 底、16px 圆角、`--shadow`；用于：更正报价（必填原因）、删除/归档确认、重复确认、导入映射批量应用确认、购买记录。危险操作按钮 primary（coral）+ 明确后果文案 |
| 下拉菜单 | 行操作（核实 / 更正 / 归档）可用 `.btn small` 内联或折叠菜单 |

### 4.11 空态 `.empty`

四种文案模板（PRD 11）：

| 类型 | 标题 | 说明示例 |
| --- | --- | --- |
| 无数据 | 还没有收录过报价 | 该商品首次录入后才会出现趋势
| 无有效报价 | 报价都在等待核实 | 核实后参与统计
| 筛选无结果 | 没有匹配的筛选结果 | 提供清除筛选按钮
| 缺少同期数据 | 暂无可比数据 | 去年同期没有已收录记录 |

### 4.12 图表（趋势 / sparkline）

- 主线：teal 3.3px 圆角；对比参考线：`#b9c5bb` 2px 虚线；数据点：白底 teal 描边 3px；最低点标注：coral 实心点 + `最低 ¥649` 文案
- **x 轴为真实时间比例轴**（非等距类别轴）；无数据日不插值（`connectNulls=false`）
- 免定金数据点：点旁加 `免定金` 微标签，hover 显示双价
- 图表必须与可排序表格并存；点击数据点 → 展开该条报价完整明细
- sparkline（分类卡）：35px 高、2.5px、按分类主色
- 无障碍：容器 `aria-label` 描述趋势摘要；数据以表格形式同步提供

### 4.13 加载态

表格/卡片用骨架屏（行高对齐、`#eef1ed` 底 shimmer）；图表用居中 spinner + 固定高度占位防跳动。

## 6. 页面规范

### 6.1 总览 `/overview`

**布局**：view-head（日期 eyebrow + 标题 + 主操作"＋ 录入报价"）→ KPI×4 → grid-hero（决策卡 + 价格脉搏）→ two-col（关注清单 + 大促日历）

**区块与功能**

| 区块 | 内容 | 数据口径 |
| --- | --- | --- |
| KPI×4 | 关注商品（其中 n 件低于目标价）/ 今日新报价（来自 n 个直播间）/ 已收录最低（商品名）/ 待核实（建议今天处理 n 条） | 全部排除 DRAFT/PENDING |
| 决策卡 | 单条最有价值的判断：标题句 + 摘要 + "查看价格证据"跳商品详情 | 文案由分析服务生成，含样本说明 |
| 价格脉搏 | 今日有变化商品：名称 / 变化描述 / 价格 / 涨跌（`↓ ¥120` 格式） | 变化基准 = 该 SKU 上一条有效报价 |
| 关注清单表 | 商品 / 最近报价 / 目标价 / 状态 tag | 按目标价接近度排序 |
| 大促日历卡 | 临近活动（活动名 / 预售期-正式期区间 / 倒计时）+ "关注清单 n 件商品待记录" | 数据源 event_period（修正 demo"接下来开播"，见 §10） |
| 待办入口 | 待补全队列（快录草稿数）、待核实数，点击直达 | — |

**交互**：KPI 待核实卡点击 → 报价管理（预筛状态）；脉搏行点击 → 商品详情。

### 6.2 商品库 `/products`

**布局**：view-head（标题 + "＋ 新建商品"）→ filter-bar（品类 / 品牌 / 状态 / 关键词）→ 表格

**表格列**：商品（缩写块 + 名称 + muted 品类·品牌）/ 规格数 / 最近报价（含发生时间）/ 已收录最低 / 关注状态 tag / 操作（详情）

**功能**：新建商品（品牌、品类、名称、别名）；商品行展开规格列表（版本、容量、数量、组合说明、状态）；新建规格；归档商品（确认弹窗，提示"保留历史报价"）；已参与比较的规格禁改比较字段，改版引导新建规格。

### 6.3 商品详情 `/products/:id`

**布局**：view-head（eyebrow 商品·品牌 + 规格标题 + "♡ 加入关注" + "＋ 记录新报价"）→ detail-hero（商品信息卡 + 深色最低价卡）→ two-col（趋势图 + 侧栏：决策面板 + 可信度卡）→ 报价明细表 → 全直播间对比入口

**区块**

| 区块 | 内容 |
| --- | --- |
| 商品信息卡 | 缩写块 / 规格编号 tag / 名称 / "共 n 条有效报价 · 覆盖 YYYY–YYYY" / 当前报价 + 较上期变化 |
| 深色指标卡 | 已收录最低报价（Display 大字）+ 来源（日期·直播间·赠品）+ 处于历史位置 mini-line |
| 趋势图 | chart-toggle：近 3 年 / 按活动；筛选：时间范围、活动、直播间；teal 主线 + 最低点标注 + 免定金点标记 |
| 决策面板 | 价格结论 tag + 结论句 / 我的目标价 / 购买意愿 / "记录为已购买"（成功 toast："报价快照已保留"） |
| 可信度卡 | 有效记录 n 条 / 来源凭证 n/m / 最近更新 |
| 报价明细表 | 列：活动 · 阶段 / 直播间 / 标称报价 / 有效价（免定金时双价）/ 赠品 / 来源 / 状态；`.current` 高亮已收录最低行 |
| 对比入口 | "查看本届全直播间对比 →" 跳 `/products/:id/compare` |

**交互**：仅 1 条有效样本 → 单点 + "样本不足"提示，不输出涨跌标签；点击趋势点 → 明细行滚动定位。

### 6.4 报价管理 `/quotes`

**布局**：view-head（标题 + "＋ 录入报价"）→ filter-bar（状态 chips：全部/待核实/有效/草稿/无效/归档 + 活动/直播间/时间筛选）→ 表格

**表格列**：商品·规格 / 直播间 / 活动·阶段 / 发生时间 / 标称报价 / 有效价 / 状态 / 来源 / 操作

**行操作与交互**

| 操作 | 交互 |
| --- | --- |
| 核实 | 确认弹窗（核对规格/价格/来源三项勾选）→ 状态变 VALID，toast |
| 更正 | Modal：展示原值 → 新值 + **必填原因**；金额/规格/时间变更走此流程；保存后更正日志可查，manual_compare_tag 置空提示 |
| 归档 | 确认弹窗（非物理删除） |
| 重复提示 | 新增时命中同规格+同直播间+同自然日+同金额 → 非阻断提示条"疑似重复，可保留"，附已有记录链接 |
| 异常提示 | 偏离近一年中位数 ±50% → amber 提示"价格异常，请核对"，仅提示 |

### 6.5 录入报价（完整）`/quotes/new`

**布局**：form-layout（左表单卡 + 右 sticky 预览）

**表单分组**（两列栅格）：

1. **基础**：商品与规格*（help：同容量/数量/组合才可比）、直播间*、活动（自动建议）、活动阶段（按 occurred_at 自动带出，可改）、发生时间*
2. **价格**：直播间报价（元）*（help：主价格口径）、直播券（未包含/已含/仅规则）、定价结构组（定金/尾款/免定金，见 4.8）
3. **赠品**：动态列表（见 4.7）
4. **优惠**：满减/其他优惠文本、买返红包（checkbox + 金额）、特殊优惠券（checkbox + 说明）
5. **来源**：来源说明*、来源类型*（单选：直播截图/官方页面/个人记录）、截图上传（提示遮挡个人信息）

**交互**：保存 → DRAFT/PENDING_VERIFY + toast"已保存，等待核实"；预览实时联动；离开未保存表单 → 确认弹窗。

### 6.6 快速录入 + 待补全队列 `/quick`（移动端优先）

**快录表单**（单列、触控 ≥44px、发生时间默认现在）：

1. 商品规格*（搜索 + 最近录入 5 条 chips 快选）
2. 直播间*（最近 3 个 chips 快选）
3. 直播间报价*（数字大键盘）

**交互**：大按钮"暂存"（300ms 防抖 + loading）→ toast"已暂存，赛后补全"→ 表单清空、焦点回规格（连续录入流）；顶部显示"本场已暂存 n 条"。

**待补全队列**（同页下半部，按录入时间倒序）：行 = 规格 / 直播间 / 价格 / 暂存时间 + amber `待补全`；行点击 → 预载完整表单；队列顶部常驻提示"先检查规格是否选对"；补全提交后从队列移除。

### 6.7 活动矩阵 `/events`

**布局**：event-head（标题 + 届次 tabs + 双轴切换 chips）→ 分类卡×3（three-col）→ 矩阵表

**双轴**

| 轴 | 行 | 列 | 回答 |
| --- | --- | --- | --- |
| 同活动跨年 | SKU | 各届同类型活动（618 2024→2026） | 这场大促逐年贵了还是便宜了 |
| 同年跨活动 | SKU | 同年各活动（38节/618/双11/双12） | 今年哪场最便宜 |

**矩阵表**：行 = SKU（product-cell）；列头 = 活动名 + 年份；单元格 = 活动内已收录最低价 + 来源阶段小标签（如 `第一波预售`）+ 免定金标记；**无记录留空**（浅灰 `—`，hover："该届无收录记录"）；活动进行中列头加 `截至当前已收录`。

**交互**：单元格点击 → 该活动该 SKU 的全部报价列表（弹层）；分类卡（护肤/彩妆/食品…）汇总该分类变化方向 + sparkline，点击筛选矩阵表；切换届次/轴 → URL 参数化可分享。

### 6.8 全直播间对比 `/products/:id/compare`

**布局**：view-head（商品名 + 活动选择器 + phase 筛选 chips「全部/预售期/正式期」+ "只看免定金" chip）→ 对比表 → 人工标签说明条

**表格**（行 = 直播间 × 规格，默认按**有效价**升序）

| 列 | 说明 |
| --- | --- |
| 直播间 | logo 块 + 名称 + 平台 |
| 规格 | SKU 名（同直播间多规格分行） |
| 定金 / 尾款 | 无定金结构显示 `—` |
| 免定金 | 勾选 ✓（coral tag） |
| 标称总价 | 口径层价格 |
| **有效价** | 默认排序列；免定金行双价"¥359（免定金）" |
| 折算单价 | 元/瓶（同款总量折算）；套装行显示 amber `需人工判断` |
| 赠品 | 摘要（`同款×1 化妆棉×1`） |
| 优惠标记 | 图标化：`买返` `特殊券` |
| 条件与来源 | 会员专属 tag / 凭证数 |
| 状态 | VALID / DRAFT（整行 opacity .55）/ 待核实（amber）/ 已过定金期（plum） |
| 我的标签 | 系统建议标签（可点击编辑 → 弹层选 CHEAPER/FAIR/EXPENSIVE/UNCERTAIN + 备注） |

**交互**：列头可切换排序（有效价/标称/折算单价）；DRAFT 行可点击"补全"直达表单；页面顶部常驻口径说明："有效价=免定金折算后实付参考；趋势与最低价统计仍用标称总价"；**不输出"哪家最划算"结论**。

### 6.9 我的关注 `/watch`

**布局**：KPI×4（全部关注/已达目标价/等降价/已购买）→ filter chips（全部/想买/等降价/已购买）→ 表格

**表格列**：商品 / 最近报价 / 已收录最低 / 目标价 / **价格状态** tag / **我的意愿** tag（两列永不相并）/ 操作

**交互**：目标价行内编辑（保存后即时重算"已达目标价"状态）；意愿下拉（未决定/想买/等降价/暂不考虑）；提醒规则说明条："提醒按有效价判断，消息同时展示标称与有效价"。

### 6.10 购买记录 `/purchases`

**布局**：filter（年份/品类）→ 表格：日期 / 商品·规格 / 数量 / 关联报价（发生时间·直播间）/ 报价快照金额 / 实付金额（个人记录，muted 注明"不进入公开报价曲线"）/ 备注

**交互**：新增购买（Modal：选规格 → 选关联报价 → 快照自动带入可复核）；关联报价被更正 → 本页快照不变 + info 提示"该报价后续有更正"。

### 6.11 导入中心 `/imports`

**布局**：三段式向导（上传 → 预览与映射 → 结果）+ 批次历史列表

| 步骤 | 内容 |
| --- | --- |
| 上传 | 拖拽区（CSV/xlsx，上限 5000 行/10MB）+ 模板下载（CSV/Excel 双格式 + 字段说明）+ 幂等说明 |
| 预览 | 三层校验结果：结构错误行清单（行号+原因）/ 关联失败行 → **映射确认表**（CSV 名称 → 候选 SKU，trigram 候选，支持勾选批量应用同名映射）/ 重复风险提示 |
| 结果 | 成功 n 条（初始待核实）/ 失败清单可下载 / 全有或全无（不产生半条数据） |

**交互**：映射确认是阻塞步骤，未确认不能提交；批量应用前确认弹窗展示映射数与规格关键信息（净含量/数量）防误伤；历史批次可查看当时明细。

### 6.12 设置 `/settings`

Tabs：基础数据（品类/品牌/直播间 CRUD，归档代替删除）/ 活动日历（各届 event_period 区间编辑，预售期/正式期，预置 2023–2026）/ 备份（导出全量/恢复演练记录）/ 账户（Token 说明）。

## 7. 全局交互模式

| 模式 | 规则 |
| --- | --- |
| 防抖节流 | 提交/暂存按钮 300ms 防抖；删除/归档 1s 节流；搜索输入 300ms 防抖后发请求 |

| 空态 CTA | 每种空态给出唯一下一步动作（去录入 / 去核实 / 清除筛选） |
| 分页 | 列表页码分页 + 每页条数切换（切条数回第一页） |

## 8. 数据展示口径规则（全站统一）

| 场景 | 展示模板 |
| --- | --- |
| 价格 | `¥` + 千分位（整数不加小数），Display 字体 |
| 下降 | `↓ ¥40`（teal）——文字+箭头+颜色，永不仅颜色 |
| 上涨 | `↑ ¥40`（coral-dark） |
| 持平 | `→ 持平`（muted） |
| 双价（免定金） | `标称 ¥399 · 有效 ¥359（免定金）` |
| 折算单价 | `¥199.5/瓶`（teal-soft 底小标签）+ "按同款总量折算"口径注 |
| 样本标注 | `共 n 条有效报价 · 覆盖 YYYY–YYYY`；比较结论旁 `样本 n` |
| 最低价 | 一律"已收录最低"，禁用"历史最低"字样 |
| 免定金过期 | 有效价旁 plum `已过定金期`，排序仍按有效价但置灰提示 |
| 时间 | 发生时间与录入时间分开展示；相对时间仅用于"21 分钟前"类辅助 |

## 9. 可访问性

- 所有可交互元素 `:focus-visible` 3px `rgba(232,102,79,.35)` 外描边（demo 已有，保留）
- 图表提供 `aria-label` 摘要 + 数据表格等价物；趋势不只靠图形表达
- 涨跌不只靠颜色（§8）；tag 色盲可辨（soft 底 + 深字对比度 ≥4.5:1）
- `prefers-reduced-motion: reduce` 关闭滚动动画与过渡
- 移动端触控目标 ≥44px；快录页全程单手可完成
- toast `aria-live="polite"`；modal 焦点圈闭 + Esc 关闭

## 12. 实现说明

- 本规范框架无关：令牌即 CSS 自定义属性（demo `:root`），可直接移植到 Vue 3 + 任意组件库的主题变量
- 组件命名沿用 demo class 名（`.btn` `.tag` `.kpi` `.pulse`…），新增组件（赠品列表、定金组、矩阵表）按本文规范命名
- 所有分析数字必须来自统一分析服务（架构 §7 `QuoteAnalyticsService`），前端**不做任何价格口径计算**，只做展示格式化——这是防口径分叉的硬约束
