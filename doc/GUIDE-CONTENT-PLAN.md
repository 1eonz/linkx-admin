## 一、交互机制说明（已确认）

| 项 | 规则 |
|---|---|
| 触发时机 | 用户**首次进入**某页面时，弹窗询问"是否查看功能引导？" |
| 确认查看 | 播放 driver.js 步骤引导；结束或中途关闭均标记"已完成" |
| 暂不查看 | 同样标记"已完成"，后续进入不再询问 |
| 手动重播 | 顶部导航栏新增"页面引导"图标按钮，仅当前页有引导配置时显示，点击直接重新播放 |
| 缓存规则 | 按用户 ID + 菜单路径存储于 localStorage；登出不清除（换账号互不影响） |
| 引导升级 | 每页配置带版本号，引导内容升级后可对已引导用户重新触发 |
| 文案语言 | 仅中文 |
| 弹窗内操作 | 一期引导只高亮页面常驻元素（搜索区、按钮、表格、页签等）；弹窗内的操作流程用文字步骤描述，不做弹窗内高亮 |
| 首步形式 | 每页第 1 步为页面概述（居中弹窗，无锚点高亮），末步附提示"可随时点击顶部引导按钮重新查看" |

## 三、各页面引导步骤详情

> 表中"引导目标"为页面上被高亮的元素（编码时为其补充引导专用 class）；"文案"为弹窗内容。

### 1. 系统设置（全局参数配置） `/baseData/globals`

| # | 引导目标 | 标题 | 文案 |
|---|---|---|---|
| 1 | （居中概述，无锚点） | 系统设置 | 本页用于管理系统的全局参数配置。配置项按类别分组展示，同一类别的配置项会合并显示。 |

## 四、开发侧说明（非业务确认项）

1. **锚点改造**：上述"引导目标"元素需在各页面补充引导专用 class（如 `guide-add-btn`），约定为引导专用、业务迭代不得随意删改。
2. **Tab 页面策略**：Tab 容器页（地图配置、协同岗、标签、应用管理、警单对接、通信服务、智能体、节点管理）引导高亮页签元素；页签内的具体操作以文字描述，必要时在 `onNext` 回调中切换 Tab 后再高亮（编码阶段按页面复杂度决定，默认不切换）。
3. **受控元素**：受权限/全局参数控制的按钮（如受 `hasPerm`、`SHOW_331_FEATURE` 控制的元素）可能在当前账号下不显示，引导步骤需在元素不存在时静默跳过该步。
4. **菜单移动**："三方注册"需后端将菜单从"系统配置"父菜单迁移至"三方对接"父菜单；前端同步修改 locales 文案（`thirdParty: '北向接入管理'` → `'三方注册'`）及 `menuRouteMapper.js` 映射归类。

## 五、待业务确认事项

1. 各页面**步骤数量与顺序**是否符合预期（是否需要增删步骤）；
