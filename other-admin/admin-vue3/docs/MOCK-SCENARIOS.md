# Mock 状态矩阵

Playwright 的 `tests/e2e/fixtures.ts` 是 Vue3 迁移期间的统一 Mock 入口。它只拦截 `/linkx/admin/**`，禁止测试写入真实后端。

## 全菜单首屏预览

- `pnpm dev:mock` 展示静态首页和 10 组、32 个动态子菜单，共 33 个入口；侧栏固定显示首页，并提供包含当前授权菜单的“全部菜单”目录、筛选与键盘导航，原有滚动导航和移动端抽屉保留。
- `mock/preview-data.ts` 与 `mock/preview-server.ts` 为 33 个入口准备首屏样例数据或配置；首页配置与警务协同、MSIP、警信版本均使用本地 Mock，轮播图 SVG 由本地 Mock 服务返回。
- `pnpm test:e2e:preview` 使用专用 Playwright 配置核对 33 个入口、目录项目与筛选跳转，遍历全部入口检查样例文案和未配置 API，检查图片自然尺寸、菜单搜索键盘导航及 390px/320px 顶栏与页面溢出，并验证北向接入筛选及增改删。该用例只验各页首屏和北向操作，不代表其余业务写操作已全部 Mock。
- `playwright.config.ts` 排除预览用例，防止它在启用真实开发代理的普通模式运行；未知预览 API 仍返回 HTTP 501。

## 可用状态

```ts
await mockBackend(page, {
  states: {
    '/authority/role/page': 'empty',
    '/api/menu/list': 'error',
    '/oauth/v2/permissions': 'unauthorized',
  },
  delayMs: 120,
});
```

| 状态           | 响应                     | 用途                         |
| -------------- | ------------------------ | ---------------------------- |
| `success`      | `code: 0` 和契约数据     | 正常入口、列表、登录和权限   |
| `empty`        | 列表为空或 `records: []` | 空态、禁用操作和分页边界     |
| `error`        | HTTP 500、业务错误码     | 错误提示、重试和状态恢复     |
| `unauthorized` | HTTP 401                 | 会话失效、清理权限和登录跳转 |
| `delayMs`      | 延迟所有响应             | 取消、切换对象和旧请求竞态   |

## 必须覆盖的业务状态

- 登录成功、密码即将过期、License 受限、权限菜单为空和普通用户。
- 列表 loading、空结果、网络失败、业务失败、分页和跨页选择。
- 保存重复点击、上传失败后移除预览、导入部分成功、下载错误。
- 底图只接受 `.mbtiles`、行政区划只接受 `.geojson`；两者均允许恰好 500 MB 并拒绝更大的文件。底图上传成功后先初始化再刷新列表；上传失败不初始化，初始化失败不刷新，删除按 `id` 查询参数提交并刷新列表。行政区划上传成功后重读并回显区域，读取失败可重试；导出沿 JSON 业务响应生成 `.geojson` 文件，导出失败显示错误。以上路径均有浏览器 Mock 用例。
- 切换 Agent/节点后旧请求晚返回、401 清理会话、动态路由重新注册。

新增接口 Mock 必须先引用 Vue2 API 契约，补充成功和至少一个失败/空态，再在迁移台账记录测试文件和未做真实联调的事实。
