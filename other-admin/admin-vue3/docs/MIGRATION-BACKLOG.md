## 权限验收矩阵

| 层级     | 输入                                      | 预期行为                                                       | 必须验证                               |
| -------- | ----------------------------------------- | -------------------------------------------------------------- | -------------------------------------- |
| 页面路由 | 菜单 `menus`、菜单 URL、全局开关、License | 仅注册允许页面；直接访问未授权地址不得显示页面                 | 管理员、普通用户、空菜单、失效 License |

权限键必须沿用 Vue2/API 契约。若后端没有区分按钮和文本的独立字段，前端只做展示层区分，不臆造新的服务端权限类型。
